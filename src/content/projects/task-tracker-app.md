## Overview

A productivity web application for managing daily tasks, projects, and deadlines with a clean and focused interface.

## Purpose

The goal was to create a distraction-free task manager that helps users organize their work without unnecessary complexity.

## What I Did

Implemented the full frontend experience, including drag-and-drop task organization, real-time filters, and responsive layouts. Collaborated on the API design and database schema to ensure smooth data flow.
